# 帮助图（站点的 `/help.jpg`）

## 怎么出图

```bash
uv run python tools/make_help_card.py
# → static/help.jpg（1080×宽，按内容自适应高度；Pillow 只在生成时需要，不进运行依赖）
```

出图后**什么都不用配**：站点会在 `/help.jpg` 提供它，插件 `比赛帮助` 会先探一下这张图
在不在——在就当场发图，没放图则回私聊文字说明（不会发破图）。换图**地址不变**。
想用别处的图，就在插件配置里填 `help_image`。

* 文字内容在 `tools/help_card_content.py`，排版在 `tools/make_help_card.py`；
* 配色 / 圆角 / 字体照站点 CSS 变量来（底 `#07090f`、卡片 `rgba(16,23,37,.92)`、
  描边 `rgba(34,224,232,.16)`、主色 `#22e0e8`、副色 `#ff2f8e`），所以图与站点是一套观感；
* **改了命令就重跑一次**（下面这份清单要一起改）；测试
  `tests/test_plugin_helpers.py::test_help_card_lists_exactly_the_same_commands`
  会比对「图上的命令」与插件 `HELP_TEXT` 里的命令，两边漂了直接红。

## 图上写了什么（也就是这份清单）

**必须先 @ 机器人，或发以 `/` 开头的命令**——直接打「比赛进度」不会触发：
命令是精确匹配的，不 @ 或没前缀时机器人不会有任何回复。

### ① 看比赛

| 命令 | 说明 |
| --- | --- |
| `比赛 [届次]` | 该届的信息 + 进度 |
| `比赛直播` | 现在谁在直播（主直播间 + 选手 / 成员机位） |
| `比赛列表 [页码]` | 全部赛事 |
| `比赛届次 [我的] [页码]` | 届次编号与名称（填参数前先发它；写「我的」只看自己创建的，多时私聊发你） |
| `比赛信息 [届次]` | 时间 / 赛制 / 人数 / 简介 / 是否排名 |
| `比赛进度 [届次]` | 已赛多少、正在打谁 vs 谁 |
| `比赛下一场 [届次]` | 接下来看哪场（含计划时间） |
| `比赛结果 [届次]` | 冠军 / 榜单 + 逐场比分 |
| `比赛冠军 [届次]` | 冠军（或积分制榜首前三） |
| `比赛名单 [届次]` | 参赛名单（选手 / 队伍 / 替补） |
| `比赛详情 [届次] [场次]` | 综合信息；给场次编号就细说那一场 |
| `比赛UID [@某人]` | 游戏 UUID（**群里直接回**；不 @ 就是你自己） |

### ② 你自己的

| 命令 | 说明 |
| --- | --- |
| `比赛我的` | 你的推流地址 + 直播间地址（私聊发你） |
| `比赛直播注册 [流名] [@某人]` | 开播要用的东西一次给全：缺推流码 / 令牌就补上（私聊发本人） |
| `比赛资料 [字段 新值] [@某人]` | 资料与改法（私聊发你）：名字 / 游戏UID / B站 / 推流码 / 直播间 / QQ |
| `比赛重置密钥 [@某人]` | 换登录密钥（旧密钥立即失效，私聊发本人） |
| `比赛重置令牌 [@某人]` | 换直播令牌（要先有推流码，私聊发本人） |
| `比赛改推流码 <流名> [@某人]` | 改推流码（等同「比赛资料 推流码 <流名>」） |
| `比赛帮助` | 就是这张图 |

> 不 @ 人 = 只动自己那份；@ 某人 = 替 TA 改（仅服务器管理员，新值仍只发 TA）。

### ③ 管理

> 召集 = **本届创建者**（就是站内说的「举办者」）或服务器管理员；授权 / 添加 = **仅服务器管理员**。

| 命令 | 说明 |
| --- | --- |
| `比赛召集 [届次]` | @ 参赛者到场（**本届创建者** / 服务器管理员，60 秒冷却） |
| `比赛授权 @某人` | 设为赛事管理员（**仅服务器管理员**） |
| `比赛添加 @某人` | 添加为普通成员（**仅服务器管理员**，登录密钥私聊发给本人） |

### 届次怎么写

`e001` / `1` / `第2届` / 名称片段都行；**必须写明**（不填会提示你补上，没有默认届次）；
「比赛直播」「比赛列表」「比赛届次」不用填；
写错了会列出候选，不会瞎猜。

### 怎么参加

参赛不用自己注册：举办者把你排进名单就行，群里 @ 你 = 要开打了。
想用「比赛我的」查推流地址，得先成为成员（服务器管理员发 `比赛添加 @你`）。
自己现在有什么、每一项怎么改：发 `比赛资料`（私聊发你一份完整清单）。

### 什么会私聊发你

命令说明、推流地址、**届次很多时的届次列表**、登录密钥、直播令牌——**都只私聊发给你本人**。
