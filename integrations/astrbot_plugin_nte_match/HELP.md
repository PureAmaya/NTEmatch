# 帮助图生成 Prompt（把下面整段复制给 AI 绘图工具即可）

用途：生成「NTE 比赛」QQ 机器人的**帮助图**，产出后存成 `static/help.jpg`
（站点会在 `/help.jpg` 提供它，插件配置 `help_image` 留空即用它）。
**样式必须与站点一致**——配色 / 圆角 / 字体照下面写死的值来，别自由发挥。

---

## 给 AI 的指令（复制这一段起）

你是一名 UI 设计师。请生成一张**中文竖版海报**，作为「NTE 比赛」QQ 机器人的使用帮助图。
要求：**所有文字逐字照抄下面给出的内容**，不要增删、不要翻译、不要用占位符（不允许出现
Lorem ipsum / 你的文字 / XXX），不要水印，不要二维码。

### 画布与整体风格（与站点一致）

* 画布：**1080 × 1920**（9:16 竖版），PNG，四周留 72px 安全边距；
* 底色：`#07090f` 近黑深蓝，自上而下极淡过渡到 `#0a0e17`，可加一层极轻的网格 / 噪点质感；
* 卡片（每个内容块）：填充 `rgba(16,23,37,0.92)`，**1px 描边 `rgba(34,224,232,0.16)`**，
  卡顶一道几乎不可见的白色高光 `rgba(186,224,255,0.07)`，圆角 **2px（直角为主）**，
  左上角切角 16px；投影 `7px 7px 0 rgba(0,0,0,0.6)`（硬阴影，不是模糊阴影）；
* 主色（强调）：青 `#22e0e8`；副色：品红 `#ff2f8e`。可用于：标题下划线、LIVE 小点、
  数字编号、分隔线上的渐变（`transparent → #22e0e8 → #ff2f8e → transparent`）；
* 正文字色 `#e6f0ff`，次要文字 `#93a7c1`，最弱文字 `#6d8098`；
* 字体气质：中文用「思源黑体 / 苹方 / HarmonyOS Sans SC」这类无衬线；
  标题用偏窄的展示体（Bahnschrift SemiCondensed / Oswald 气质），**全大写英文标签**；
  命令名、地址等技术文本用等宽字体（JetBrains Mono / Consolas 气质）。
  小标签（如 `NTE MATCH · BOT HELP`）用等宽 + **字距 0.22em** + 10~12px；
* 整体气质：深色科技面板、克制、清晰可读——**这是工具说明图，不是赛博朋克海报**，
  不要霓虹光晕、不要粒子爆炸、不要人物插图。

### 版面结构（自上而下）

1. **顶部标题区**：左侧小标签 `NTE MATCH · QQ BOT`（等宽、青色），
   主标题 `比赛机器人 · 使用说明`（大字、白色），副标题（弱色）
   `在群里 @ 机器人，或按唤醒前缀发命令`;
2. **醒目提示条**（横贯整宽、青色描边、左侧一个青色圆点）：
   `必须先 @ 机器人，或发以 / 开头的命令` + 换行小字
   `直接打「比赛进度」不会触发：不 @ 或没前缀时机器人不会有任何回复`;
3. **命令表**：三张卡片，标题分别为 `① 看比赛`、`② 你自己的`、`③ 管理（仅服务器管理员）`。
   每行格式：**命令名**（等宽、青色）+ 一行说明（弱色）。逐字照抄：
   * ① 看比赛
     * `比赛 [届次]` —— 该届的信息 + 进度
     * `比赛直播` —— 现在谁在直播（主直播间 + 选手 / 成员机位）
     * `比赛列表 [页码]` —— 全部赛事
     * `比赛届次` —— 全部届次的编号与名称（填参数前先发它）
     * `比赛信息 [届次]` —— 时间 / 赛制 / 人数 / 简介 / 是否排名
     * `比赛进度 [届次]` —— 已赛多少、正在打谁 vs 谁
     * `比赛下一场 [届次]` —— 接下来看哪场（含计划时间）
     * `比赛结果 [届次]` —— 冠军 / 榜单 + 逐场比分
     * `比赛冠军 [届次]` —— 冠军（或积分制榜首前三）
     * `比赛名单 [届次]` —— 参赛名单（选手 / 队伍 / 替补）
     * `比赛详情 [届次] [场次]` —— 综合信息；给场次编号就细说那一场
   * ② 你自己的
     * `比赛我的` —— 你的推流地址 + 直播间地址（私聊发你）
     * `比赛重置密钥 [@某人]` —— 换登录密钥（旧密钥立即失效，私聊发本人）
     * `比赛重置令牌 [@某人]` —— 换直播令牌（要先有推流码，私聊发本人）
     * `比赛改推流码 <流名> [@某人]` —— 改推流码（英文 / 数字；令牌不变）
     * `比赛帮助` —— 就是这张图
     * 卡片底部**加一行小字**：`不 @ 人 = 只动自己那份；@ 某人 = 替 TA 改（仅服务器管理员，新值仍只发 TA）`
   * ③ 管理（仅服务器管理员）
     * `比赛召集 [届次]` —— @ 参赛者到场（60 秒冷却）
     * `比赛授权 @某人` —— 设为赛事管理员
     * `比赛添加 @某人` —— 添加为普通成员（登录密钥私聊发给本人）
4. **两张并排的小卡片**（高度一致）：
   * 标题 `届次怎么写`，内容：
     `e001 / 1 / 第2届 / 名称里的几个字` 都行；
     `不填 = 当前主赛事；比赛直播与比赛列表不用填届次`;
     `写错了会列出候选，不会瞎猜`;
   * 标题 `怎么参加`，内容：
     `不用自己注册：本届举办者把你排进名单就行`;
     `群里 @ 你 = 要开打了；想查推流地址先成为成员（服务器管理员发「比赛添加 @你」）`;
5. **一条私聊说明（弱化处理，底部）**：
   `命令说明、你的推流地址、登录密钥、直播令牌都只走私聊发给你本人` +
   `（发不出去时会提示你先加机器人好友）`;
6. **页脚**：`@机器人 比赛帮助` + 站点地址占位（小字、弱色）。

### 硬性要求（务必满足）

* 中文必须**逐字准确、不缺笔画、不打错字**；英文与符号（`@` `[]` `<>` `/` `——`）保持原样；
* 命令名与说明**左右对齐成一列**，不要换行拆断命令名；
* 整张图信息密度高但不拥挤：卡片之间留 24px，行距 ≥ 1.5 倍字号；
* 不要出现任何没在上文列出的命令；不要把 `@机器人` 写成 `@ 机器人` 以外的东西；
* 输出为**单张竖图**，不要拼图、不要多页。

## 出图之后

1. 存成站点项目的 `static/help.jpg`（换图**地址不变**，插件侧不用改配置）；
   想放别处就在插件配置里填 `help_image`（图片网址 / AstrBot 本机路径都行）。
2. **命令改了要一起改这里**：本文件的命令清单与插件里的 `HELP_TEXT` 是同一份内容，
   测试会拦住「其中一处漏了某条命令」；但拦不住「图还是旧版」——重做图这件事只能靠人记。
