# 帮助图（站点的 `/help.jpg`）

## 怎么出图

```bash
uv run python tools/make_help_card.py
# → static/help.jpg（1080×宽，按内容自适应高度；Pillow 只在生成时需要，不进运行依赖）
```

出图后**什么都不用配**：站点会在 `/help.jpg` 提供它，插件 `比赛帮助` 会先探一下这张图
在不在——在就当场发图，没放图则回私聊文字说明（不会发破图）。换图**地址不变**。
想用别处的图，就在插件配置里填 `help_image`。

* 文字内容在 `app/helpcard_content.py`（**在 `app/` 里**：这张图现在是服务启动时自动生成的，
  内容得跟着应用一起发布），排版在 `app/helpcard.py`（手工重画用 `tools/make_help_card.py`）；
* 配色 / 圆角 / 字体照站点 CSS 变量来（底 `#07090f`、卡片 `rgba(16,23,37,.92)`、
  描边 `rgba(34,224,232,.16)`、主色 `#22e0e8`、副色 `#ff2f8e`），所以图与站点是一套观感；
* 字体是**简体中文**那一支：多语言合集（`NotoSansCJK-*.ttc` / `SourceHanSans*.ttc`）里
  同时装着 JP / KR / SC / TC，取错一支会把简体字画成日文字形——所以优先取简中单语言
  文件，退而求其次时按 face 名挑（见 `app/fonts.py` 的 `_sc_face_index`）；
* **改了命令就重跑一次**（下面这份清单要一起改）；测试
  `tests/test_plugin_helpers.py::test_help_card_lists_exactly_the_same_commands`
  会比对「图上的命令」与插件 `HELP_TEXT` 里的命令，两边漂了直接红。

## 图上写了什么（也就是这份清单）

图**只列命令**：一屏看完、能直接贴群公告。以前那几块引导语（「必须先 @」「第一次用看这三步」
「届次怎么写」「怎么参加」、页脚提醒）都撤了——图越长越没人看，而那些话在 `比赛帮助`
私聊回来的**文本说明**里本来就有一份（见 `HELP_TEXT` 与 `HELP.md` 下面的说明）。

### ① 看比赛

| 命令 | 说明 |
| --- | --- |
| `比赛 [届次]` | 信息 + 进度 |
| `比赛直播` | 谁在直播（主直播间 + 机位） |
| `比赛列表 [页码]` | 全部赛事 |
| `比赛届次 [我的] [页码]` | 编号与名称；多时私聊发你 |
| `比赛信息 [届次]` | 时间 / 赛制 / 人数 / 规则（发卡片图） |
| `比赛进度 [届次]` | 已赛多少、正在打谁 vs 谁 |
| `比赛下一场 [届次]` | 接下来看哪场 |
| `比赛结果 [届次]` | 先发结果图：逐场比分 + 对阵树 |
| `比赛冠军 [届次]` | 冠军（或榜首前三） |
| `比赛名单 [届次]` | 参赛名单（选手 / 队伍） |
| `比赛详情 [届次] [场次]` | 综合信息；给场次就细说那场 |
| `比赛UID [@某人]` | 游戏 UUID（群里直接回） |
| `比赛UUID [届次]` | 本届选手的 UUID 清单 |

### ② 你自己的

| 命令 | 说明 |
| --- | --- |
| `比赛报名 [届次]` | 报名参赛（筹备中；只定名单） |
| `比赛取消报名 [届次]` | 取消报名（成员身份留着） |
| `比赛我的` | 你的推流地址 + 直播间地址 |
| `比赛直播注册 [流名] [@某人]` | 开播要用的东西一次给全 |
| `比赛资料 [字段 新值] [@某人]` | 资料与改法 |
| `比赛重置密钥 [@某人]` | 换登录密钥 |
| `比赛重置令牌 [@某人]` | 换直播令牌 |
| `比赛改推流码 <流名> [@某人]` | 改推流码 |
| `比赛帮助` | 就是这张图 |

> 不 @ 人 = 只动自己那份；@ 某人 = 替 TA 改（新值仍只私聊发 TA）。

### ③ 管理

> 召集 = **本届创建者**（就是站内说的「举办者」）或服务器管理员；授权 / 添加 = **仅服务器管理员**。

| 命令 | 说明 |
| --- | --- |
| `比赛召集 [届次]` | @ 参赛者到场（举办者 / 服管，60 秒冷却） |
| `比赛授权 @某人` | 设为赛事管理员（仅服务器管理员） |
| `比赛添加 @某人` | 添加为普通成员（仅服务器管理员） |

### 图上没有、但文本说明里有的

`比赛帮助` 私聊回的那段文字（插件 `main.py` 的 `HELP_TEXT`）讲得细一些，下面几条只有那里有：

* **必须先 @ 机器人**，或按 AstrBot 里设的唤醒前缀发（例如 `/比赛进度`）——直接打
  「比赛进度」不会触发：那是 AstrBot 的命令过滤规则，不是插件能改的；
* **届次怎么写**：`e001` / `1` / `第2届` / 名称片段都行；**必须写明**（不填会提示你补上，
  没有默认届次）；「比赛直播」「比赛列表」「比赛届次」不用填；写错了会列出候选，不会瞎猜；
* **怎么参加**：本届还没开赛（筹备中）时发 `比赛报名 <届次>`——只定名单，不组队不定赛制，
  组队与赛程等报名结束由管理员在网站上安排；要退出就发 `比赛取消报名 <届次>`。
  开赛 / 结束后名单冻住，报名会被拒绝（会说清卡在哪一条）。报名白名单群里的新人也能直接报名：
  站点顺手把你加成成员，登录密钥私聊发你；别的群请先让管理员把你加为成员；
* **什么会私聊发你**：命令说明、推流地址、登录密钥、直播令牌，以及届次很多时的届次列表。
  私聊发不出去时资料与说明会退回群里说一声；**登录密钥与直播令牌不会**——它们只显示一次，
  泄在群里等于白送一个账号。
