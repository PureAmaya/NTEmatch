NTE 比赛 · QQ 机器人帮助


比赛
  功能：某一届的信息 + 进度
  使用说明：必须写明届次——写名称（如 春节）或编号（如 e001）
  例子：@机器人 比赛 春节
        @机器人 比赛 e001

比赛直播
  功能：现在谁在直播——主直播间 + 正在推流的选手 / 成员机位，附观看地址
  使用说明：直接发，不用填届次
  例子：@机器人 比赛直播

比赛列表
  功能：全部赛事，分页
  使用说明：可以带页码（从 1 开始）；不填就是第 1 页
  例子：@机器人 比赛列表
        @机器人 比赛列表 2

比赛届次
  功能：全部届次的编号与名称
  使用说明：直接发，不用填届次；填届次前先发它，看有哪些届可以填
  例子：@机器人 比赛届次

比赛信息
  功能：某一届的时间 / 赛制 / 人数 / 简介 / 是否排名
  使用说明：必须写明届次（名称或编号，如 春节 / 第2届 / e001）
  例子：@机器人 比赛信息 春节
        @机器人 比赛信息 e001

比赛进度
  功能：某一届已经打了多少、正在打谁对谁
  使用说明：必须写明届次（名称或编号，如 春节 / 第2届 / e001）
  例子：@机器人 比赛进度 春节
        @机器人 比赛进度 e001

比赛下一场
  功能：某一届接下来看哪场（含计划时间）
  使用说明：必须写明届次（名称或编号，如 春节 / 第2届 / e001）
  例子：@机器人 比赛下一场 春节

比赛结果
  功能：某一届的冠军 / 榜单 + 逐场比分
  使用说明：必须写明届次（名称或编号，如 春节 / 第2届 / e001）
  例子：@机器人 比赛结果 春节
        @机器人 比赛结果 第2届

比赛冠军
  功能：某一届的冠军是谁（积分制的届给榜首前三）
  使用说明：必须写明届次（名称或编号，如 春节 / 第2届 / e001）
  例子：@机器人 比赛冠军 春节

比赛名单
  功能：某一届的参赛名单——选手 / 队伍 / 替补
  使用说明：必须写明届次（名称或编号，如 春节 / 第2届 / e001）
  例子：@机器人 比赛名单 春节

比赛详情
  功能：某一届的综合信息；再带上场次编号就细说那一场（双方、比分、时间）
  使用说明：必须写明届次，可以再带场次编号（如 春节 L-1）
  例子：@机器人 比赛详情 春节
        @机器人 比赛详情 春节 L-1

比赛召集
  功能：@ 某一届的参赛者，喊他们到场准备
  使用说明：必须写明届次；只有本届举办者 / 服务器管理员能用；同一会话 60 秒内只能发一次
  例子：@机器人 比赛召集 春节

比赛我的
  功能：你自己的推流地址 + 站点里的直播间地址
  使用说明：直接发，不用填届次；按发命令的 QQ 认人，结果私聊发你
  例子：@机器人 比赛我的

比赛授权
  功能：把群友设为赛事管理员（能管自己创办的届）
  使用说明：要真的 @ 到那个人（手打 QQ 不认）；只有服务器管理员能用
  例子：@机器人 比赛授权 @张三

比赛添加
  功能：把群友添加为普通成员（能登录站点、改自己的资料）
  使用说明：要真的 @ 到那个人（手打 QQ 不认）；只有服务器管理员能用
  例子：@机器人 比赛添加 @张三

比赛帮助
  功能：把这份说明发给你
  使用说明：直接发，不用填届次
  例子：@机器人 比赛帮助
